## 🧾 About the Project

This project is a **frontend UI clone** of Salesforce CRM — the world's leading customer relationship management platform. Built entirely with **HTML5 and CSS3**, it replicates the look and feel of Salesforce's dashboard and interface components without any JavaScript frameworks or CSS libraries.

It's a great project for:
- 🎓 Practicing advanced CSS layout techniques
- 🖼️ Recreating professional enterprise UI designs
- 💼 Showcasing frontend skills in a portfolio

> ⚠️ This is a **fan-made, non-commercial** UI clone for educational purposes only.

## 🚀 Getting Started

No installation or build process needed! This project runs directly in the browser.

### Option 1 — Open Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/harshit8204/salesforce-ui.git
   ```

2. **Navigate into the folder**
   ```bash
   cd salesforce-ui
   ```

3. **Open in your browser**
   ```bash
   # Simply double-click index.html
   # OR open it via terminal:
   open index.html        # macOS
   start index.html       # Windows
   xdg-open index.html    # Linux
   ```

### Option 2 — Live Server (Recommended for Development)

If you use VS Code, install the **Live Server** extension:
1. Right-click `index.html`
2. Select **"Open with Live Server"**
3. Auto-reloads on every save ✅
